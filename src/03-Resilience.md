# Resilience

Preserve continuity when optimization is no longer the priority.

---

## Core Idea

Under fatigue, failure, or scarcity,
the goal shifts from improvement to survival.

---

## Scope

It asks:

- When should the system step down instead of pushing harder?
- How can minimum function be restored quickly?
- How can missing capability be replaced locally?
- How can workflows remain executable under low cognitive bandwidth?

---

## Mechanisms

- Controlled de-escalation
- Minimal recovery
- Local substitution
- Low cognitive load operation

---

## Output

- reduced operating modes
- minimal recovery paths
- substitute implementations
- low-burden workflows

---

## Boundary

Resilience does not:

- decide what is true
- gate irreversible action
- organize cooperation
- define expression interfaces

---

> A constrained system does not need to win. It needs to remain usable.
