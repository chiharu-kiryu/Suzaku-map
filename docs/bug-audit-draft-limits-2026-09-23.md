## 已确认的三种边界

- **自动联想：256 个 Unicode 码点**，不是 256 字节。超过后原生 IBus 保留完整
  原文候选，不发送新的预测请求；此前在途或已返回的候选不能重新覆盖长草稿。
  删短后可以重新联想，当前字段已经提交的上下文不因越界而丢失。
- **伴随镜像：单项文本 8192 个 UTF-8 字节、整帧至多 65536 字节**。
  无法安全编码时发布无正文/候选的受保护帧，而不是截断文字。这复用协议的
  `private` 标记，**不等于将真实输入框改成隐私字段**。超过文本上限的原生草稿
  仍保留在 IBus，可继续编辑和回车提交；删短到可镜像范围后恢复。
- **面板替换：8192 个 UTF-8 字节**。超限或含控制字符的替换被完整拒绝，不能
  清空原稿或只采用前半段。这与原生物理键盘草稿、独立字面提交通道的限制不同。

以上是已有行为，不是本轮新增功能。超长草稿无法继续完整显示在悬浮面板，仍是一项
使用限制；本轮没有扩大协议预算、自动分段提交或取消安全检查。

## 新增的可重复检查

### 原生输入边界：72 组

[隔离原生夹具](../scripts/test-native-sync.py) 使用真实的私有 IBus 引擎对象，组合
三种语言 × 六种输入 × 恰好/超过上限 × 直接提交/先退格恢复，共 **72 组**。

六种输入是普通字母、Alt 字面数字、空格、死键重音、254 字节 Compose 结果，以及
无效 Compose 的字面数字收尾。初始草稿同时含汉字、emoji、重音和 JSON 需要转义
的引号/反斜杠；按 UTF-8 字节构造边界，避免把字符数误当成长度预算。

每组检查超长/控制字符替换不改变草稿；编辑不隐式提交；旧版本动作被拒绝；镜像
越界时不泄出截断正文；退格恢复完整镜像；真实 CommitText 信号与完整预期逐字
一致；随后短草稿候选可正常恢复。仍不等于真实桌面应用之间的联动验收。

### 异步模型边界：8 组

四种编辑（字母、emoji、空格、长 Compose）× 请求在途/结果已就绪，共 **8 组**。
初始草稿恰好 256 码点、UTF-8 字节数大于 256。回环模拟服务用事件控制回复，验证：

- 长度变大后只有完整本地原文，迟到结果不复活，也不新增超预算请求。
- 纯编辑不结束当前输入目标，不产生提交。
- 缩短后发出新的请求，精确保留同字段历史，并可完整提交新模型候选。

只访问夹具自有的回环 HTTP 服务，不连接实际模型或云服务；不评估语言质量。

### 宿主序列化边界：30 组

[宿主模块单测](../src/ime_host.rs) 新增 **1 项顶层测试**，内部覆盖三语 × 五种
文本 × 恰好/超过 8192 字节，共 **30 组**。文本包括 ASCII、密集 JSON 转义、
汉字与重音、四字节 emoji、可打印不换行空白。

检查真实 C 接口产生的帧可被客户端解析、帧长度有界、目标/版本/语言不变；超限
只遮蔽镜像，不改变宿主草稿、选中载荷或字段隐私状态；完整原文仍能提交。
