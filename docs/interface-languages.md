# 界面语言

在 **Settings → Appearance → Interface**（设置 → 外观 → 界面语言）选择语言。
支持英语、简体中文、日语、韩语、西班牙语、法语、德语和葡萄牙语。
语言按钮始终保留各语言自己的名称，方便切换回来。

- 默认 **System / 跟随系统**：按 `LC_ALL`、`LC_MESSAGES`、`LANG` 的顺序读取第一个
  非空系统环境设置，支持地区与编码后缀；无法识别或未设置时回退英语。
  系统环境在启动时确定；手动选择则即时生效，无需重启。
- 面板、设置、托盘、操作提示、翻译状态使用随程序附带的静态语言资源，不请求模型或网络。
  操作系统及外部服务返回的原始诊断、路径、服务名、键名等仍保留原文，便于排障。
- 设置搜索同时匹配当前界面语言和原始英语标签；拉丁字母搜索支持 Unicode 大小写转换。
  长标签按实际字体宽度排版，较窄窗口会将设置名称放在选项上方，选项自行换行。
- `ui_language` 存在面板设置中，保存、重启、配置备份与恢复均保留它。
  老配置缺少这个字段时使用 System，无法识别的面板设置值也回退 System；备份导入会拒绝
  不支持的语言值。没有新增模型下载或配置迁移步骤。

## 三种语言独立

**界面语言**只改变程序按钮和说明。**输入语言**仍通过托盘选择中、英、日输入引擎。
**翻译源语言／目标语言**只影响显式的草稿翻译请求。切换界面语言不会改写草稿、候选词、
转写文本、手写结果或模型译文，也不会改变输入语言、模型选择或云端授权。

## 维护

语言类型与回退规则在 `src/ui.rs`，语言资源在 `src/ui/catalog.tsv`。
每行依次是英语原文键和中、日、韩、西、法、德、葡七种译文。
动态消息中的 `{}` 槽位只代入原始参数，不再次翻译参数。不要把用户文本交给界面本地化接口。
测试检查资源完整性、重复键、槽位对应、切换与持久化、搜索和换行，以及实际字体渲染。
