# 文本翻译

展开面板工具区，点 **文** 图标进入 Translation。原文就是上方可编辑草稿，IBus 激活时
来自当前非隐私输入框的组合文本，不读取剪贴板、选中文本或周边输入历史。

1. **From** 可选 Auto 自动识别，或者明确指定源语言。
2. **To** 选择目标语言。八种语言分别是英语、简体中文、日语、韩语、西班牙语、法语、
   德语和葡萄牙语；缩写按钮悬停可查看完整名称。
3. 点击 **Translate** 才发起请求。翻译不依赖自动候选联想开关，不会替你开启该开关。
4. 长译文用左右箭头分页。**Use draft** 将完整译文替换到草稿，仍须回车或明确选择发送。
   IBus 使用当前宿主、上下文和修订号确认替换；拒绝或未确认时保留原文，不自动重试。
   替换确认后收起翻译工具，恢复候选界面；迟到的确认不会关闭后来打开的工具或新翻译。

重复点击已经选中的源语言或目标语言不会取消正在进行的翻译，也不会清空已有译文。

0.5.9 也保护尚未松开的 Translate 手势：按下后换输入框、原文变化或取消，
松开不会把新草稿送给模型，需要重新点击。同框纯状态刷新不受影响。
见 [翻译请求边界审计](bug-audit-translation-2026-09-23.md)。

0.5.9 修复采用译文后立刻使用屏幕键盘的时序问题：如果成功确认先到、
新草稿快照尚未到，后续文字先接在已确认的译文后，等匹配的新版本到达再发送。
中途换框不会携带旧草稿；断连或与实体键盘修改冲突时保留恢复文本，不自动覆盖或重试。
见 [工具回填后的连续输入审计](bug-audit-insertion-followup-2026-09-23.md)。

## 模型与隐私

复用 [模型服务配置](model-providers.md) 的模型、协议、端点、密钥引用和云端授权。
默认仅发现本机已安装模型，优先 LLaMA；不会下载权重、自动开启云端或修改输入语言。
支持 Ollama `/api/chat` 和 OpenAI-compatible chat completions，使用独立的翻译提示，
不使用候选词提示、手写提示或已提交上下文。云端翻译仍需明确授权。

0.5.7 只使用已确认的模型目标。保存配置后请通过托盘重新加载；若磁盘上的目标或云端授权
与面板已确认配置不同，点击翻译会提示重新加载，不向新旧任一目标发送草稿。配置读取失败
同样不会发送。这项检查也保留了磁盘撤销云端授权后的拒绝路径，但不能追回已发送的数据。

每次最多 1,000 个原文字符、2,000 个译文字符，生成总时间上限 30 秒（包括发现）。
模型响应须为完整译文；使用普通文本生成，不套用候选 JSON schema，以免小模型在约束
解码时损伤非拉丁文本。拒绝截断、空值、超限和不支持的控制字符，明显未转换到中日韩
文字的拉丁句子也会报错。此字符检查不能证明语义准确，请在替换草稿前核对译文。
原文和译文仅保留在内存中，不进设置、备份或日志。

0.6.6 在源文本前重申翻译任务，并要求保留问句、否定、数字和段落，避免把问候直接当聊天
问题回答。原文中的 `?` / `？` 数量若在译文中减少，拒绝使用该结果并提示保留原稿；
不会给一个回答强行补问号。这是保守的标点契约检查，**不是语义判定**：问号仍在也可能
翻错，不带问号的错误问句改写也无法靠它识别；某些省略问号的正常译法会被要求重试。

短请求（原文不超过 512 UTF-8 字节且系统提示与用户消息合计不超过 1280 字节）使用
512-token 输出上限；Ollama 复用候选的 2048-token 上下文大小，避免短翻译反复触发
上下文大小切换/模型重载。长请求仍为 4096-token 输出、8192-token Ollama 上下文。
翻译采样温度为 0，总超时仍为 30 秒；这些设置不影响候选的温度或默认 1200 ms 预算。

compatible 接口的工具转交、未知完成状态或错误字段类型也不视为完整译文；正常 `stop`
和旧接口缺失/`null` 完成状态仍受支持，不执行任何模型工具调用。

修改原文、切换源/目标语言、离开翻译工具、隐藏面板、改变 IBus 上下文或重载配置时，
未使用的旧结果失效。**Cancel** 丢弃结果和尚未发出的任务，无法收回已发往服务的文本；
已开始的调用受超时限制，不阻塞界面。翻译失败不修改草稿，也不偷偷重试或改用云端。

当前组合编辑器是单行的：分页预览保留译文段落，替换到草稿时换行/制表转换为空格。
八语是翻译请求能力，不等于八套拼音/罗马音输入引擎；输入法仍支持已有中、英、日输入。
具体翻译质量取决于选用模型对相应语言的能力，尤其是小型本地模型。

本机 `llama3.2:3b` 的合成样例实测能返回八语文本；改进提示后中文问候样例保留了问句，
日文报告问句的错误改写被标点检查拒绝。但日文仍有内容遗漏/错译，韩文也有未翻译的英文
片段；不能宣称中日韩语义问题已全部解决，详见 [实模修正审计](bug-audit-model-latency-2026-09-24.md)。
普通测试和字符/标点检查不等于翻译质量评估；正式使用前请核对，
需要高质量中日韩互译时应另行选择能力更强的多语言模型。本功能不会替你更换或下载模型。
