# Suzaku 0.7.4 · Reliable model fallback and broader bilingual vocabulary

For **Ubuntu 24.04 amd64, IBus, X11 / GNOME XWayland**. This remains an Alpha;
keep a fallback input method. Other platforms are not newly release-qualified.

## Highlights

- **Broader local fallback:** three authored expansions add **658 explicit English word
  forms**, **488 Chinese readings** and **272 short sentences per language**. Including words
  projected from phrases, the deduplicated English index grows from 5,251 to **5,934**;
  Chinese grows from 1,143 to **1,631 readings**. English has 273 next-word contexts and 510
  sentences; Chinese has 265 continuation contexts and 528 sentences.
- **Everyday coverage:** clarification and offline trouble, work and travel, scheduling,
  shopping/after-sales and daily conversation. Real English inflections and regional forms
  are explicit; Chinese uses authored syllable boundaries, including unfinished last-syllable
  completion. These are forms and curated examples, not unique lemmas or a general accuracy score.
- **Independent fallback data:** vocabulary still uses embedded, validated JSON resources,
  separate from decoders, platforms and model providers. Local choices are available immediately,
  even while model requests are pending, and survive disabled, missing, failed, timed-out or
  empty providers. There are no new input-path file/network reads, downloaded corpora, model
  installations, runtime imports or hot reload. Old ranks, homophones and Japanese data remain.
- **Learned sentences survive full model batches (N57):** previously a frequent local sentence
  could be removed before its preference bonus was applied. Preferences now rank the bounded
  merge pool before the final cutoff. The pool still has at most 12 local candidates, six model
  replies and six derived words; the display remains at most 12 candidates, six per page.
  Word/sentence quotas, literal input, typing anchors and explicit selection locks are retained.
- **Deeper fallback QA:** 36 authored scenarios per language, Chinese in four spellings,
  30 standalone English word forms, four unfinished Pinyin cases, literal case/spacing/
  apostrophes and long drafts. Private IBus checks cover actual loopback HTTP 503/deadline
  failures; 36 real GTK workflows verify physical input, adoption, undo, Space and saved commits.

Preferences remain bounded, decaying and memory-only, with private-field exclusion and tray
clearing. The fix does not create text or change model consent. Space still continues a draft;
Enter or a candidate click submits. Language shortcuts and configuration formats are unchanged.

## Validation and limits

Before the metadata-only version bump, the final implementation passed **963 Rust tests,
0 failures and 27 opt-in skips**, strict all-feature/all-target Clippy, both complete private
IBus modes and **36 real GTK vocabulary workflows**. Each native mode includes 12 actual
HTTP 503/deadline workflows as well as the full-model preference regression. Older data
fingerprints remain checked rather than being rerecorded to hide reordering.

After the version bump, the complete Rust suite again passed **963 tests, 0 failures and
27 opt-in skips**, and strict all-feature/all-target Clippy passed. Version/build metadata,
both macOS plists, Python/Bash syntax, paired functional diagrams and all **229 source audit
links** were checked. Third-party lockfile package entries match 0.7.3 unchanged.
All four Linux release binaries built successfully; the newly built release panel and host
then passed all **36 real GTK vocabulary workflows** on a private display. These were the
release binaries, not a reuse of the older personal installation or a debug-only check.

Local `.tar.gz` and `.deb` packages passed checksum, manifest, binary-version, launcher,
content and non-installing CLI smoke checks, including **250 tarball / 214 Debian audit
documentation links** (the tarball also checks flattened guides). These are worktree QA artifacts, not published assets or
clean-container installation acceptance. The personal installation was not upgraded;
release-check logs and packages are retained in the task-owned `szrelease074.*` directory.

The N57 English/Chinese regressions failed before the fix. Each vocabulary round also first
exposed missing authored examples on the older data. Failure and final logs are retained;
these are regression examples, not evidence of unrestricted language quality or a live model
benchmark. See the [N57 audit](../bug-audit-preference-model-2026-09-27.md) and
[three-round vocabulary record](../ibus-candidates.md#模型不可用时的本地兜底词库).

Builds and native checks run serially with one Cargo job in task-owned user scopes using
`MemoryHigh=2G`, `MemoryMax=3G`, `MemorySwapMax=0`. No unrelated processes, desktop limits or
personal input sources are changed. Original suite deadlines and candidate budgets remain.
Local validation, remote CI, clean-container installation and personal-desktop acceptance
are distinct. Native Wayland, arbitrary applications and actual model quality are not newly qualified.

Rust/lockfile, macOS bundle versions and Android metadata use **0.7.4**. Bundle build numbers
and the Android version code are **28**; third-party dependency versions are unchanged.
A source commit/tag does not update the installed application or attach GitHub Release assets.
Downloadable Linux packages and checksums are required starting with **0.8.0**, as recorded
in [Linux packaging](../linux-packaging-data.md#从-080-开始的发布要求).

## Install and upgrade

Once matching assets are available, verify `suzaku_0.7.4_amd64.deb` with
`sha256sum -c suzaku_0.7.4_amd64.deb.sha256`, finish/cancel the draft, fully quit Suzaku,
then use `sudo apt install ./suzaku_0.7.4_amd64.deb`. Update panel and host together.
Source/user installations likewise need rebuilding and reinstalling to use the embedded
vocabulary and merge fix. Existing settings, privacy and explicit cloud-consent rules remain.
This source release does not upgrade the older personal installation or register services.
