# Suzaku 0.6.0 · Linux Alpha input-state and model-context release

For **Ubuntu 24.04 amd64, IBus, X11 / GNOME XWayland**. This remains an Alpha;
keep a fallback input method. Other platforms are not release-qualified.

This release collects functional-network fixes **N29–N32** after 0.5.9. Continuous drafting,
explicit submission, provider consent and no-automatic-replay rules are unchanged.

## Highlights

- **Reselecting the current language (N29):** choosing the same language or a normalized alias
  preserves the draft, one-step completion undo and pending dead-key/Compose sequence. Only a real
  language change clears them; reloading a provider still retains the current field's draft.
- **Repeating prediction settings (N30):** choosing the current prediction switch or Tone no longer
  rebuilds candidates, unlocks the selected result or requests the same model completion again.
  Conditional persistence still checks configuration conflicts and write failures. Explicit reload
  still reconfigures the engine, even if the saved values are unchanged.
- **Native engine destruction (N31):** destroying the focused IBus engine without an earlier
  FocusOut ends that field's session, cancels its prediction state and publishes an unfocused empty
  companion frame. Late model results cannot restore it. Destruction of an older, unfocused engine
  clears only that object's local state and cannot disrupt a newer field.
- **Exact native model context (N32):** consecutive candidate commits accumulate their exact text,
  including existing spaces, without adding the independent editor's automatic separators. For
  example, committing `foo` then `bar` records `foobar`, matching the delivered candidate payloads.
  Application output and the independent editor's spacing/undo behavior are unchanged. Model
  requests remain limited to the current field's last 160 characters of candidate-commit context;
  Suzaku does not read surrounding application text.

## Validation and compatibility

- Feature-enabled regression suite: **825 passed, 0 failed, 24 opt-in tests skipped** by the ordinary
  command. Skipped tests are not counted as passed.
- Private runners passed **16 panel UI groups and 1 executable-startup group**, **3 settings groups**,
  and the complete native IBus chain. These checks were rerun with the 0.6.0 metadata.
- Strict Clippy passed for both `--all-features --all-targets` and `--features gpu --all-targets`
  with `-D warnings`. Formatting, whitespace and the modified packaging script's ShellCheck passed.
- Rust/lockfile, macOS and Android version metadata agree. All **50 audit-document links** checked
  in the source tree resolve. Reports are included in the explicit Linux documentation package list;
  this is not a built-package validation.
- Staged secret scanning found no leaks.

New regression coverage includes **95 native scenarios**: **41** same-value control, save-failure
and candidate-lock cases, **34** focused/stale engine destruction and controlled model-reply cases,
and **20** exact native/model-context cases across English, Chinese and Japanese. These scenarios
run inside the private IBus suite, not as additional top-level Rust tests. The **2** new Rust tests
for native context and independent-editor spacing/undo are already included in the 825 above.

Panel/settings tests use private Xvfb/D-Bus, synthetic frames and action queues; IBus tests use a
private native host and input contexts. Model tests only use owned loopback fixtures. None operates
the development desktop's input method, a real microphone or model account; these checks do not
establish full GNOME/Wayland, arbitrary-application or other-platform acceptance.

Rust, macOS bundle and Android app metadata all use **0.6.0**; the bundle build number and Android
version code are **14**. This aligns metadata without expanding native-platform support.

## Install and upgrade

This source release is not an attached binary package. Once matching release assets are available,
verify `suzaku_0.6.0_amd64.deb` with `sha256sum -c suzaku_0.6.0_amd64.deb.sha256`, fully quit Suzaku,
then install using `sudo apt install ./suzaku_0.6.0_amd64.deb`. Existing configuration is retained.
See [Linux packaging/data](../linux-packaging-data.md) for source builds and package validation.
No package is installed as part of preparing this release. Fresh distributable packaging and
container installation/upgrade/removal are not rerun for this source commit; local checks do not
imply remote CI has run or release assets exist.

Linux speech remains a simulated bridge, handwriting and offline CJK dictionaries remain limited,
and input/recovery drafts are still in memory. This release adds no migration, model download, cloud
consent or change to Enter/candidate-click submission.
