# Suzaku 0.8.1 · Native candidates and everyday bilingual fallback

For **Ubuntu 24.04 amd64, IBus, X11 / GNOME XWayland**. This remains an Alpha;
keep another input method available. Other platforms are not newly release-qualified.

## Highlights

- **One candidate surface by default:** Suzaku's custom panel takes over only after actually
  presenting a native draft. A host/context-bound lease hides the duplicate system lookup UI;
  hiding, folding or locally editing the panel restores it. Crashes and UI stalls fall back
  automatically without another key. Expiry is 1.2 seconds after the last accepted renewal,
  or up to about 1.8 seconds from a UI stall. Display ownership never commits or changes a draft.
- **Safer activation and editing:** tray activation prepares visibility before queued work.
  Opening settings or editing local text keeps that interaction visible; late native snapshots
  no longer overwrite a local draft while focus events are pending.
- **Everyday bilingual fallback:** Chinese adds 132 readings, including 很强、很厉害、少糖、
  带伞 and 临时有事. Both languages gain everyday replies, feelings, food preferences,
  weather/outings and changing plans. Totals are **6,111 English forms / 2,175 Chinese readings**,
  **425 / 419 contexts** and **814 / 836 authored sentences**. Prior ranks and Japanese data remain.
- **Eleven optional collections:** eight new English/Chinese study-writing, cooking, travel and
  work packs add 240 explicit English forms, 144 Chinese readings and 256 sentences before
  deduplication. All are model-independent JSON; nothing is installed automatically.
- **Linux registration recovery:** safely recognizes the specific IBus “No global engine”
  response after component replacement, then restores and verifies the recorded input source
  within the existing deadline. Other command failures remain errors; existing service
  enable/disable preferences are retained.

Built-in words and sentences remain bounded fallback, not open-ended generation. Optional packs
and the Python SDK stay independent of model providers. Restart both host and panel after pack
changes; no live reload, executable plugins or settings-panel pack manager is added. Space keeps
writing; Enter or a candidate click submits. No input history, models or personal data are bundled.

GTK3 transport gates passed during development; see the [validation record](../linux-packaging-data.md).

After synchronizing the release metadata, all **1,030 Rust tests** passed again (0 failures,

Publish the `.deb`, binary `.tar.gz` and both SHA-256 files only after **this exact clean commit's**

## Install / upgrade

Download the matching files from the 0.8.1 GitHub Release. Finish or cancel the current draft,
fully quit Suzaku, then on Ubuntu 24.04 amd64:

```bash
sha256sum -c suzaku_0.8.1_amd64.deb.sha256
sudo apt install ./suzaku_0.8.1_amd64.deb
/usr/bin/suzaku-panel
```

For a first installation, register explicitly **as your desktop user, without sudo**:
`/usr/bin/suzaku-tool linux-register install`. Package installation alone neither activates input
nor registers/starts a user service. Upgrade host and panel together; existing configuration,
cloud consent and user pack data remain. Keep original pack JSON files for recovery.

For the tarball, verify `suzaku-0.8.1-x86_64-unknown-linux-gnu.tar.gz.sha256`, extract and verify
the included `SHA256SUMS`, then start `./bin/panel`. It is not a static universal Linux build.
Source/user-level installations require a separate rebuild/reinstall. See [installation and data](../linux-packaging-data.md),
[input behavior](../ibus-candidates.md), [known limitations](../known-limitations.md) and [privacy](../privacy.md).
