# Suzaku 0.5.5 · Linux Alpha preview

For **Ubuntu 24.04 amd64, IBus, X11 / GNOME XWayland**. Keep a fallback input method.
macOS/Windows are compile-checked, not release-qualified.

## Highlights

- English word/sentence continuation through spaces and partial words, readable long-candidate
  suffixes, and draft-only Ctrl+Backspace.
- Numeric/decimal/phone fields no longer consume digits as candidate choices. Screen-keyboard
  bursts retain unsent edits; stable letter presses survive candidate refreshes.
- Eight interface languages and explicit model-backed draft translation, independent of the
  three native composition languages and the specific model/provider.
- Sharper glyphs, compact tabbed settings, optional system title bars and transparent borderless
  exteriors with driver fallback.
- Hardened Linux packages, explicit runtime/font dependencies, and isolated installation, upgrade,
  removal and registration checks. Configurations/backups survive package removal.

## Install and upgrade

Download `suzaku_0.5.5_amd64.deb` and its checksum; verify with
`sha256sum -c suzaku_0.5.5_amd64.deb.sha256`. Fully quit Suzaku before upgrading.
Install with `sudo apt install ./suzaku_0.5.5_amd64.deb`.
On first installation, run `/usr/bin/suzaku-tool linux-register install` and
`/usr/bin/suzaku-tool linux-register verify` as the desktop user without sudo, then open
`/usr/bin/suzaku-panel`. Explicit registration retains the active input method.
Package installation itself does not register, activate or download a model.

The tarball requires compatible runtime libraries; it is not a universal/static package.
Checksums are integrity checks, not signatures. Model weights and user data are not bundled.

## Important limitations

Dead-key/Compose accents remain unreliable; use the usual keyboard for those. Native Wayland,
other distributions/architectures and broad app compatibility need more testing. Chinese/Japanese
dictionaries are small; Linux speech is simulated. Translation quality depends on the model.
Input/recovery drafts are in memory. Cloud use needs explicit consent and may incur charges.
