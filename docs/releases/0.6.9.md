# Suzaku 0.6.9 · Linux Alpha vocabulary, long drafts and panel ergonomics

For **Ubuntu 24.04 amd64, IBus, X11 / GNOME XWayland**. This remains an Alpha;
keep a fallback input method. Other platforms are not release-qualified.

Chinese and English remain the priorities. This release includes the installed ergonomics
follow-up, audit round 45 and the curated vocabulary expansion. Existing Japanese input,
eight interface/translation languages and model-provider independence remain intact.
Space continues the draft; numeric choices adopt editable text; Enter or a deliberate
candidate click submits.

## Highlights

- **More offline vocabulary:** the deduplicated English index grows from **1,242 to 3,906**
  explicit forms, including everyday, travel, office and development words. Next-word groups
  grow from 65 to 81 and authored sentences from 80 to 128. Chinese Pinyin entries grow from
  **98 to 602**, with 41 continuation contexts and 80 sentences. These are curated forms,
  not independent word roots or a complete dictionary. No third-party corpus, personal
  input history, learning database or automatic model download is introduced.
- **Useful words and sentences together:** joined/separated Pinyin, optional tone digits,
  homophones and adopted-space continuation keep their existing boundaries. A stable
  first-letter Pinyin index preserves authored order. New ambiguous alternate conversions
  no longer crowd explicit local/model sentence continuations off the first page; primary
  conversion and literal input remain selectable. Unknown text is not forcibly corrected.
- **Local completion in longer drafts:** English and adopted-Chinese drafts beyond
  256 code points use a bounded local tail, then reattach the exact earlier prefix. Long
  unconverted Pinyin, URLs and identifiers are not arbitrarily split. Existing text/frame
  budgets remain **8192/65536 UTF-8 bytes**; fewer candidates fit near the limit, without
  truncating candidate text. Chinese labels show differing tails while submission retains
  the full text. The model-request limit remains **256 code points**; Japanese is unchanged.
- **Keyboard-operable settings:** visible Tab/Shift+Tab and arrow-key focus, Enter/Space
  activation, Ctrl+F search and scroll-to-focus reuse existing actions and save acknowledgements.
  Read-only shortcuts, folded/offscreen options and IME preedit do not become accidental buttons.
  These are in-window controls, not new global activation shortcuts or full screen-reader support.
- **Panel ergonomics and privacy:** zoom controls are larger and separated, scale reset uses
  live state, and GNOME/X11 orb presses wait for movement before handing a drag to the window
  manager. A stationary click can expand the orb again. Window titles no longer contain
  user drafts, committed text or debug hints; synthetic frame logging is explicit test-only behavior.
- **Reliable regression fixtures:** constant dictionary tests compare contents instead of
  addresses, runtime-report checks use fixed readiness fixtures instead of racing live probes,
  and long-draft native observers drain frames per key. Test instructions document required
  features, session toolchain visibility and short Unix-socket fixture paths.

## Validation and compatibility

Local checks on the changes included in this release:

- Full-feature Rust suite: **897 passed, 0 failed, 27 ignored**. The ignored tests require
  explicit environments; ordinary suite success does not mean every opt-in gate ran.
- Strict all-feature/all-target Clippy, Rust formatting and the four input-quality suites
  (**30 tests**) pass, including authored/model sentence ranking and long-tail literal preservation.
- Complete private IBus suites pass in default and inline-preedit modes. Each includes
  **36** bilingual word/sentence adoption workflows, **32** long-draft workflows and **12**
  exact model-prefix workflows, alongside existing privacy, cancellation and recovery cases.
  These were rerun after vocabulary/ranking fixes before the version-only metadata update;
  no personal desktop input source was changed.
- Earlier included-change audits separately record **17** isolated UI checks, **11** GTK groups
  with eight long-draft scenarios, and installed ergonomics/zoom/orb checks. Their original
  dates, test counts, failures and installation scope are retained in the linked reports;
  they were not repeated as a fresh full desktop matrix for this source release.
- Release metadata, the rebuilt CLI version, formatting, changed shell-script syntax and
  all **17** Python scripts check cleanly. All **45** audit reports plus the ergonomics report
  are in the packaging manifest, **204** audit links resolve, and the two functional-network
  diagrams agree. Staged changes and existing Git history pass the checksum-pinned secret scan.

Rust/lockfile, macOS bundle and Android metadata use **0.6.9**. Bundle build numbers and the
Android version code are **23**. Dependency versions are unchanged; metadata alignment does
not expand platform support.

The expanded vocabulary has no independent corpus accuracy or performance benchmark. Real-model
semantics/latency, native Wayland, arbitrary applications/remappers, hardware LEDs, touch ergonomics
and screen-reader accessibility remain separate acceptance work. Routine model fixtures use synthetic
text and controlled providers. Native replacement still rejects control characters; core newline
coverage does not introduce native multiline editing.

Remote CI, binary package creation and installation are separate from these local/source checks.
This release operation does not replace the installed application or turn older failed CI runs green.

## Install and upgrade

This is a source commit/tag, not an attached binary package. Once matching assets are available,
verify `suzaku_0.6.9_amd64.deb` with `sha256sum -c suzaku_0.6.9_amd64.deb.sha256`, fully quit
Suzaku, then use `sudo apt install ./suzaku_0.6.9_amd64.deb`. Upgrade the panel and host together.
Existing settings, shortcut preferences and cloud-consent rules are retained; no personal data or
model weights are added to packages. Source/user installations must likewise replace matching binaries.

Hosts registered before 0.6.5 still need explicit re-registration for the N43 retry policy.
After upgrading and fully quitting, use the matching new tool as the desktop user, without sudo:

```bash
/usr/bin/suzaku-tool linux-register install
/usr/bin/suzaku-tool linux-register verify
```

These are `.deb` paths; source/user installations should use their corresponding tool. See
[Linux installation and data](../linux-packaging-data.md) for dependencies and safe upgrade/removal.
