# Suzaku 0.7.0 · Linux Alpha continuous word-to-sentence input

For **Ubuntu 24.04 amd64, IBus, X11 / GNOME XWayland**. This remains an Alpha;
keep a fallback input method. Other platforms are not release-qualified.

Chinese and English remain the priorities. This release includes audit rounds 46–47,
N54/N55 and the stock-popup CI fixture correction. Existing vocabulary, Japanese input,
eight interface/translation languages and model-provider independence are unchanged.
Numbers adopt editable choices; Space continues the draft; Enter or a deliberate candidate
click submits. There are no new global shortcuts or automatic commits.

## Highlights

- **Sentence choices survive word adoption:** N54 retains the complete authored Chinese
  phrase and its horizontal spacing in the bounded local window. Adopting `你好` in a long
  draft no longer removes its known sentence continuations, before or after Space.
  Longest matching phrases take priority: `我想学习中文` is not reduced to just `中文`.
- **No gap when a draft becomes shorter:** N55 shares that suffix match with the ordinary
  IBus mix. Converting a 258-code-point Pinyin draft to 254 code points no longer drops
  sentence choices when switching out of the long-draft path. Earlier text and literal
  spacing stay intact; URLs, paths, email addresses and identifiers retain their guards.
- **Continuous editing remains explicit:** paired English/Chinese checks cover typing and
  deleting punctuation, undoing word/sentence adoption, continued spacing and exact submission
  in a real GTK editor. No input reaches the application merely by adopting a candidate.
- **Model boundaries remain independent:** local continuation does not enlarge the whole-draft
  **256-code-point** model budget. A 260→256→257→256 transition stops/resumes full-draft requests
  and rejects stale replies. The local window, **8192-byte** mirror text and **65536-byte** frame
  limits remain unchanged; this is not arbitrary paragraph generation or a larger dictionary.
- **Stock-popup CI regression fixed:** the 0.6.9 vocabulary expansion made `hel` offer ten
  candidates while the test required exactly nine. The fixture now clicks every actual slot,
  still requiring a full first page and a partial last page, stable candidate counts, correct
  ordinal signals and exact saved text. No assertion is skipped or timeout relaxed.

## Validation and compatibility

- Full-feature Rust suite: **904 passed, 0 failed, 27 ignored**. Opt-in environments remain
  separate; ordinary suite success does not qualify every desktop or external model.
- Strict all-feature/all-target Clippy and Rust formatting pass. The five targeted language,
  long-draft and prediction suites contain **53 passing tests**.
- Default and inline-preedit private IBus suites pass, including **28** word-to-sentence
  adoption workflows each. They cover threshold changes, Space, punctuation deletion,
  exact undo and explicit single commits, alongside the existing synchronization/privacy gates.
- Real GTK / GNOME Text Editor checks pass in a private Xvfb session, including **4** new
  word-to-sentence workflows. Drafts remain absent from the application until submission;
  the saved full text is checked, not a candidate preview.
- Stock IBus popup checks pass: **47** workflows, including **18** ordinal-glyph checks.
  Source audit reports, packaging-manifest coverage and offline links are retained.
- The rebuilt CLI reports 0.7.0, all **47** audit reports are listed in the Linux packaging
  manifest, **217** local audit links resolve and the two functional-network diagrams agree.
  Changed shell-script and Python syntax checks pass. Staged changes and existing Git history
  pass the checksum-pinned secret scan.

Rust/lockfile, macOS bundles and Android metadata use **0.7.0**. Bundle build numbers and
the Android version code are **24**. Dependency versions are unchanged; metadata alignment
does not expand platform support. Historical audit counts and installed-state reports remain
as originally recorded.

This is a source commit/tag, not an attached binary package or an installation update.
Remote CI and distribution-package checks are separate; the old 0.6.9 failed run remains failed.
Native Wayland, the full browser/Qt matrix, hardware LEDs, accessibility and real-model quality
are not newly qualified by this release. No personal input history or model weights are bundled.

## Install and upgrade

Once matching assets are available, verify `suzaku_0.7.0_amd64.deb` with
`sha256sum -c suzaku_0.7.0_amd64.deb.sha256`, finish/cancel the draft, fully quit Suzaku,
then use `sudo apt install ./suzaku_0.7.0_amd64.deb`. Upgrade the panel and host together.
Existing settings, shortcuts and cloud-consent rules are retained. Source/user installations
must likewise replace matching binaries. Hosts registered before 0.6.5 still require explicit
re-registration for the service retry policy; see [Linux installation/data](../linux-packaging-data.md).
