# Suzaku 0.5.7 · Linux Alpha reliability patch

For **Ubuntu 24.04 amd64, IBus, X11 / GNOME XWayland**. This remains an Alpha;
keep a fallback input method. Other platforms are not release-qualified.

This patch collects the follow-up functional-network fixes **N05–N18** after 0.5.6.
It does not add a new model dependency or change Space into a submission key.

## Highlights

- **Continuous completion and undo:** independent-panel word buttons and Back no longer discard
  a new rapid gesture just because it uses the previous button position. When next-word suggestions
  run out, pending completion history keeps a compact, usable Back row. Duplicate releases and
  stale candidate presses remain blocked; large text fits the row. Native IBus retains its existing
  one-step Backspace completion undo and explicit submission rules.
- **Tool insertion:** automatic voice insertion stays bound to its original field/context. Focus
  changes, disconnection or private fields stop automatic insertion and retain the source draft for
  manual use. Voice/handwriting insertion in the independent editor respects the caret and existing
  separators. Linux speech remains a simulated bridge, not production microphone transcription.
- **Settings recovery:** startup snapshots and late acknowledgements do not overwrite newer choices.
  Conditional saves and writer locks reject stale model/consent settings instead of overwriting an
  externally edited file. Appearance-save failures retain the preview and expose unsaved/retry feedback.
- **Model boundaries:** independent-panel suggestions use the confirmed provider configuration until
  an explicit reload. Translation refuses to send when the configured target or cloud consent conflicts
  with the on-disk settings. Compatible chat replies with incomplete, tool-transfer or unknown finish
  states do not become candidates or translations; invalid replies retain the existing fallback behavior.
- **Data restore safety:** running-instance and writer locks cover configuration symlink layers and
  their resolved targets. Alternate runtime directories and atomic saves must not bypass restore gates.
  Do not manually retarget configuration symlinks while Suzaku is running; stop and restart first.
- **Linux registration and packaging:** failed first-registration autostart steps can be retried without
  losing a user's later disabled preference. `linux-register diag` is read-only, like `verify`.
  Desktop queries, service operations and previous-IME restoration have bounded timeouts. Packages
  include the additional audit reports and rebase/check links in every flattened guide, including
  the model and translation guides at both documentation-root and tarball-root locations.

## Validation and compatibility

- Feature-enabled regression suite: **818 passed, 0 failed, 19 opt-in tests skipped** by the ordinary
  command. Skipped tests are not counted as passed.
- Separate private runners passed: **12 UI groups, 3 settings groups, 2 data/restore groups**, the
  native IBus chain and the private file-manager fixture. These use synthetic drafts/configuration
  and do not operate the development desktop's input method or real model accounts.
- Strict Clippy passes with `--all-features --all-targets` and `--features gpu --all-targets`, using
  `-D warnings`. Formatting, whitespace, Linux script lint and staged secret scanning pass.
- The four optimized Linux release binaries build successfully and report the matching tool version.
  Linux CI additionally builds `.deb`/`.tar.gz` packages, checks contents/checksums/launchers and runs
  installation, upgrade and removal in a clean Ubuntu container. The source tag alone does not mean
  those remote checks have finished or binary assets have been attached.

Rust, macOS bundle and Android app metadata all use **0.5.7**; the bundle build number and Android
version code are **11**. This is metadata alignment, not expanded native-platform acceptance.

## Install and upgrade

A source tag is not an attached binary package. Once matching release assets are available,
verify `suzaku_0.5.7_amd64.deb` using
`sha256sum -c suzaku_0.5.7_amd64.deb.sha256`, fully quit Suzaku, then install with
`sudo apt install ./suzaku_0.5.7_amd64.deb`. Existing configuration is retained.
Source builds and CI package artifacts are alternatives; see [Linux packaging/data](../linux-packaging-data.md).
Installation itself does not activate/register the input method, download models or migrate drafts.

No personal configuration, credentials, model weights or generated packages belong in this source
release. Cloud suggestions still need explicit consent. Input/recovery drafts remain in memory;
this patch does not add autosave, complete Chinese/Japanese dictionaries, native Wayland acceptance
or a guarantee of real-model language quality.
