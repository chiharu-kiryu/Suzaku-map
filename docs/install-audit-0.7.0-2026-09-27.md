# 0.7.0 本机重装与输入实测（2026-09-27）

按用户要求，把现有用户级安装从 0.6.8 加人机工程学修复更新到 **0.7.0 / `de60147`**。
环境是 Ubuntu 24.04、GNOME / X11、IBus；本次没有安装系统级 `.deb`、发布新版本或改动产品代码。
本轮结果来自重新执行，不能用发布前测试或历史实测的通过数代替。

## 安装与状态保护

- 四个程序用 `cargo build --locked --offline --release --all-features` 构建，
  沿用 `~/.local/libexec/suzaku/`、现有命令链接和桌面启动器；安装文件与 release
  构建逐字节一致。运行中面板和 systemd 宿主的可执行文件也核验过，没有沿用旧进程。
- 开始时面板、宿主均已停止，输入源是 Rime，服务原有自启动偏好为 enabled。
  先备份四个旧程序、个人配置、服务、组件及启动器，再原位替换并显式重新注册。
  组件版本为 0.7.0，安装后与测试结束时的只读 `linux-register verify` 均通过。
- 当前个人偏好为中文、标准快捷键、LLM 关闭、青龙主题、100% 比例、隐藏系统标题栏。
  桌面输入测试通过宿主确认的接口临时切换中英，结束后恢复中文。
- 两份个人配置、服务文件和启动器最终均与备份逐字节一致；GNOME 输入源列表/MRU、
  Caps/Num Lock 与原状态一致，桌面 IBus 进程未重启。最后输入源为 Rime，新版面板与宿主运行。
- 私有回滚材料和日志保存在用户备份目录 `install-0.7.0-20260927.*`；
  不把个人配置、运行日志或桌面材料加入仓库。没有请求模型、下载权重或输入个人文档。

## 真实 GNOME 桌面补验

创建专用 GTK TextView，连接已安装宿主。每次 XTest 注入前检查焦点属于本进程窗口
或其真实子窗口；键盘已有按键按下或焦点离开便停止，仅释放测试自己按下的键。
所有样本都是合成文字。长稿只通过伴随面板接口提供前缀，后续拼写、空格、数字采用、
标点、撤回和提交均经真实键盘事件；不把整个长稿称作逐字物理输入。

**已通过 13 组，整套未完成：**

- 9 组英文基础操作：词句候选、数字采用/撤回、Tab 双向导航、Shift+Enter、
  数字长按一次采用、空格续写与单次 Enter 提交、字面数字、Shift 大写、连续草稿及双空格。
- 300 字符英文前缀后的 `please sen → please send → please send me the details.`。
- 无前缀的 `ni hao → 你好 → 你好，很高兴认识你。`。
- `前文。` 后采用 `我想学习中文`，空格续写后仍有本地句子候选。
- 252 个汉字前缀后采用 `你好`，仍可选句、删标点恢复候选、精确撤回和单次提交。

第 14 组（254 个汉字前缀后的 `hui yi`）输入期间焦点转到测试窗口以外，保护检查
中止并销毁专用窗口，随后恢复中文偏好与 Rime；没有在其他窗口继续输入。
因此这组和之后的中文声调数字组 **不记为真实桌面通过**。对应路径的隔离 GTK 回归
已通过，但不能替代桌面补验。需用户方便短暂保留测试窗口焦点时再续测；不自动抢回焦点。

另行通过实际托盘完整退出：服务停止并跨过 2 秒重试间隔保持停止；重新启动安装版
面板后服务自动启动，输入源仍为 Rime。没有故意终止桌面 IBus 或改变自启动偏好。
