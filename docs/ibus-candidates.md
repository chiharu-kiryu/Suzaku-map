# IBus 词句候选体验

本轮针对 Linux 原生 IBus 候选窗；英、中、日语言仍由托盘的「输入语言」切换。
不启动新的键盘监听器，不切换其他应用的输入焦点。

## 输入与候选

| 模式 | 输入 | 本地词候选示例 | 本地句子候选示例 |
| --- | --- | --- | --- |
| English | `hel` | `hello`、`help` | `hello, how are you?` |
| 中文拼音 | `nihao` / `ni hao` | `你好` | `你好，很高兴认识你。` |
| 日本語・ローマ字 | `nihongo` / `niho` | `日本語` | `日本語を勉強しています。` |

英文保留大小写、空格和原始字母。中文支持连续拼音和分隔拼音；日文支持罗马音补全、
假名转换，以及小词库的分段汉字转换，例如 `nihongo wo benkyoushitai` → `日本語を勉強したい`。
原文始终保留为可选项，未知标识符不会被随意拼接成本地英文句子。

末词还没有拼完时，也会保留前面已经识别的内容，例如 `woxihuanbei` → `我喜欢北京`、
`watashihanihong` → `私は日本語`，同时提供已覆盖的短句搭配。`ᵂ` 在这种情况下表示
补全最后一个词，提交/补全的替换文本仍包含整个预编辑，不能丢掉前缀。
接受转换后还能继续字母输入，例如 `日本語` 后接 `wobenky` → `日本語を勉強`。
中文空格和撇号明确保留音节边界：`xi an` / `xi'an` → `西安`，与 `xian` → `先` 区分。

离线句子来自明确的常用搭配，不是假装由模型生成。启用「LLM 联想」后，本地/云端模型
异步补充候选，统一接口请求词和短句两类输出，不依赖 LLaMA 或其他特定模型名称。
没有模型、超时或结果无效时，离线候选仍可使用。

这是基础词库和短句联想，不是完整中日文词典、日文形态分析器或任意长句转换系统。
不是每个未知拼写都能生成两类有效候选；有结果才显示，不用无关句子凑满列表。

## 上下标和排序

例如 `hello ᵂ₉₂`、`hello world ˢᴬᴵ₈₅`：

- `ᵂ`：词补全；`ˢ`：短语/句子；`ᴿ`：原文。
- `ᴬᴵ`：由模型新增的候选。本地候选与模型重复时只调整权重，不改写本地来源。
- 下标 `₀`–`₁₀₀`：排序权重，**不是正确率、置信概率或持久化学习统计**。
- 行号 `¹`–`⁶`：当前页的选择编号，与右侧权重无关。

无法可靠分类的日文未完成读音仅显示权重，不把半截假名标成句子。

候选最多 12 个，每页 6 行。英文原文与最佳本地词补全、中文/日文首个本地转换保持固定，
以免模型返回后 Space/Tab 的目标变化。其余项按有界权重排序；首页在可用时预留两项词和
两项句子的位置，因此类型覆盖与固定首项优先于全列表严格降序。无法满足配额时不填假项。
开始选择后锁定列表，直到下一次编辑；旧请求不能覆盖新输入。

预览包含上下标最多 42 个 Unicode 码点，超长句加省略号。提交使用独立的完整原文，
不会提交行号、上下标、省略号或 AI 标记。伴随面板也继续接收完整文本和选择索引，
新类型/来源/权重字段是协议 v1 的可选扩展，旧帧仍可解析。

使用 Unicode 上下标，而非依赖自定义字体大小或 HTML 标记。
[IBus 标准文本属性](https://github.com/ibus/ibus/blob/main/src/ibusattribute.h)
不提供任意垂直偏移属性；具体字形、字号和候选窗外观仍由桌面 IBus 面板及系统字体决定。

## 键盘

| 操作 | 效果 |
| --- | --- |
| Tab / Shift+Tab、方向键 | 下一项 / 上一项 |
| PageDown / PageUp | 下一页 / 上一页，每页 6 项 |
| Alt+1–6 | 三种语言均选择当前页对应项并提交 |
| 1–6 | 中文/日文选择当前页；英文仍输入普通数字 |
| Shift+Space | 已显式选中候选时采用该候选，再加分隔空格；否则仅插入分隔空格，继续连写 |
| Shift+Enter（含小键盘 Enter） | 将当前候选放回预编辑，不上屏、不加空格；词与完整 AI 句子均可继续编辑 |
| 补全后立即 Backspace | 撤回刚才的补全，恢复原拼写；普通输入或再次选择候选后恢复逐字符退格 |
| Space | 提交所选项；英文附加一个空格 |
| Enter | 提交所选项，不附加空格 |
| Esc | 清空本次预编辑和候选 |

例如英文输入 `please`，Shift+Space，再输入 `sen`，会保留 `please sen` 并给出
`please send` 和短句。日文分隔空格不进入转换后的日文，但完整罗马音原文仍可选择。
输入 `hel` 后 Tab 选中 `hello`，Shift+Space 得到可继续编辑的 `hello `，而不是 `hel `。
这两个补全操作不会生成应用提交事件、不会加入已提交上下文，也不会带入候选展示标记。
仅保留一步临时撤回内容；清空、切换语言、切换隐私状态和失去焦点都会清除它，不写入磁盘。
AltGr、Ctrl/Alt 组合应用快捷键不作为选词键。密码/PIN 输入继续直接绕过引擎；
隐私字段不请求模型，也不向伴随面板暴露候选。

## 验证范围

运行 `bash scripts/test-linux-ci.sh ibus`，在独立 D-Bus/IBus 会话中验证三语候选、
上下标/字体回退、6 项翻页、中日文末词补全、连续输入、预编辑补全/撤回、数字与 Alt 快捷键、长句完整提交、异步选择锁定、
隐私边界和宿主重启。模型路径使用固定本地测试服务，不上传真实输入，也不加载实际模型。
不同桌面外观和实际模型联想质量仍需对应环境实测。
